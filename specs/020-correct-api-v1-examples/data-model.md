# Data Model: Correct API v1 Examples

## Entities

- PageRoute: path, canonical URL, title, description, h1, indexability, schema blocks.
- ApiExample: displayed URL, copied URL, rendered image src, expected content type.
- InternalLink: source page, href, route type, redirect status.
- MeasurementSnapshot: date, source, query, page, impressions, clicks, position, crawl issue, backlink metrics.
